Quelle est la différence entre Git et GitHub ?
Git est un logiciel qui permet de suivre et de gérer les modifications apportées aux fichiers d'un projet.

GitHub est une plateforme en ligne qui permet d'héberger, de partager et de collaborer sur des projets utilisant Git.

En résumé : Git gère les versions d'un projet, tandis que GitHub permet de stocker et de partager ce projet en ligne.
