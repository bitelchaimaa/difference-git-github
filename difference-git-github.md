# Différence entre Git et GitHub

## 1. Git

Git est un système de gestion de version qui permet de suivre les modifications apportées à un projet, de sauvegarder les différentes versions du code et de revenir à une version précédente si nécessaire.

## 2. GitHub

GitHub est une plateforme en ligne qui permet d'héberger, de partager et de collaborer sur des projets informatiques en utilisant Git.

## 3. Différence entre Git et GitHub

Git est un logiciel qui fonctionne principalement sur l'ordinateur local pour gérer les versions d'un projet, tandis que GitHub est une plateforme en ligne qui permet de stocker ces projets et de faciliter leur partage et la collaboration entre utilisateurs.
